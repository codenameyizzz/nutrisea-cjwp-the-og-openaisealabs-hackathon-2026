## 2. Core Value Proposition

NutriSea menjembatani *intention-action gap* pekerja kantoran urban yang ingin hidup sehat namun mengalami *cognitive overload* (kelelahan mental menghitung kalori di jam kerja) melalui Co-Pilot nutrisi otonom yang langsung mengeksekusi pesanan makanan bergizi seimbang di ShopeeFood pada rentang harga lokal terjangkau dan terhubung dengan tabungan mikro SeaBank.
